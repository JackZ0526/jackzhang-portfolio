## Prompt

Create a polished portfolio project cover for "BOARD GAME AI", a personal engineering series combining GomokuAI and XiangqiAI. Landscape 16:10. Use the two reference images to faithfully identify the actual game objects: Gomoku is a 9x9 intersection board with plain black and ivory stones; Xiangqi is a 9x10 intersection board with flat round Chinese-character pieces, a river and palace diagonal lines. This is an editorial illustration, not a screenshot.

Art direction: sophisticated minimal technology-company visual, physical board-game tactility meets computational search. Near-black charcoal background, carefully lit warm pale wooden board surfaces, black/ivory Gomoku stones and cream Xiangqi discs with red/black engraved Chinese characters. Two beautifully rendered board fragments side-by-side in one coherent, shallow three-quarter perspective across the lower/right two-thirds. Crop board edges deliberately so no need to depict a whole match; never merge the two games onto one board. Xiangqi pieces are flat cylinders, never Western chess figures. Gomoku stones sit on intersections. Show a tiny restrained ice-blue branching line connecting a few possible move intersections, as an abstract search visualization, with at most three small luminous dots. Realistic soft shadows, precise geometry, high material quality, mostly matte. No shattered pieces, robot heads, brains, neon circuitry, decorative HUD widgets, numbers, fake performance graphs or invented interface.

Typography in generous upper-left negative space: large elegant clean sans serif "BOARD GAME" on one line, "AI" below; small secondary line "GOMOKU / XIANGQI". White typography, quietly confident, not futuristic stencil. Keep all type and main objects inside 8% safe margin. Excellent contrast and instantly legible at thumbnail size, balanced breathing room, no excessive empty space. A restrained, premium minimal AI lab cover that complements a charcoal-and-cyan portfolio. All non-piece text in English; exact title spelling.
